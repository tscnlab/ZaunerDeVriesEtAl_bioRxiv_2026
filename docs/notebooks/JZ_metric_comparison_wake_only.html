Derive wake and sleep duration denominators

Timing differences are expressed relative to the behavioural interval in which the underlying metric is defined. The sleep interval follows the preparation workflow and extends from diary-recorded sleepprep (when the devices were positioned for the night) to wake. Diary intervals are restricted to participant-dates retained in the prepared metrics, with each interval assigned to its wake date. Mean sleep duration is the grand mean across all retained diary intervals, so each retained night receives equal weight. Mean wake duration is the complement of mean sleep duration to 24 hours. The three darkest-10-hour timing outcomes are classified as darkness-based; all other timing outcomes are classified as brightness-based. The darkness-based timing outcomes are not retained in this wake-only sensitivity analysis, but the sleep-duration denominator is still reported for consistency across scenarios.

Fit models

The same engines and stepwise complexity reduction used by the primary analysis are applied. If required, the date random effect is removed first, then the participant-specific position slope is reduced to an intercept, and finally the site-position interaction is removed.

Model fitting helpers
#| label: fit-model-helpers
#| filename: Model fitting helpers
main_formula <- value ~ site * position + site + position + (position | Id) + (1 | Date)
red_formula <- value ~ site * position + site + position + (position | Id)
red_formula2 <- value ~ site * position + site + position + (1 | Id)

rhs_same <- function(f1, f2) {
  identical(
    attr(terms(formula(f1, rhs = 1)), "term.labels"),
    attr(terms(formula(f2, rhs = 1)), "term.labels")
  )
}

fit_model <- function(data, formula, engine, family) {
  if (is.null(formula)) {
    return(NULL)
  }

  model <- switch(
    engine,
    "lm" = lm(formula, data = data, contrasts = list(site = "contr.sum")),
    "glm" = glm(
      formula, data = data, family = family,
      contrasts = list(site = "contr.sum")
    ),
    "lmer" = lmer(formula, data = data, contrasts = list(site = "contr.sum")),
    "glmer" = glmer(
      formula, data = data, family = family,
      contrasts = list(site = "contr.sum")
    ),
    "glmmTMB" = glmmTMB(
      formula, data = data, family = family,
      contrasts = list(site = "contr.sum")
    )
  )

  did_converge <-
    performance::check_convergence(model) && !check_singularity(model)

  if (!did_converge) {
    if (rhs_same(main_formula, formula)) {
      formula <- update(formula, . ~ . - (1 | Date))
    } else if (rhs_same(red_formula, formula)) {
      formula <- update(formula, . ~ . - (position | Id) + (1 | Id))
    } else if (rhs_same(red_formula2, formula)) {
      formula <- update(formula, . ~ . - site:position)
    } else {
      return(model)
    }
    model <- fit_model(data, formula, engine, family)
  }

  model
}
