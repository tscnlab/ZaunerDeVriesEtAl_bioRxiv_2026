Preparation of metrics for participant-day analyses - wake-only sensitivity

Sensitivity analysis: documented non-wear and diary-defined sleep removed

Author

Johannes Zauner

Preface

This document prepares a wake-only sensitivity dataset from the same primary-analysis participant-day sample used in JZ_metric_preparation.qmd. The existing 50% hourly and 80% daily completeness checks are applied before diary-defined sleep is removed, so planned sleep does not make a day fail a 24-hour completeness rule. Immediately before metrics are calculated, measurements are set to missing during documented non-wear and diary-defined sleep. Pre-sleep time is retained, and absent state information is treated as undocumented rather than inferred.

The wake-only estimand is each participant-day’s light exposure during valid, concurrent waking wear at the glasses, chest, and wrist positions. Timestamps and missing epochs are preserved. Missing periods therefore break threshold episodes and cannot be mistaken for darkness or silently join measurements from opposite sides of sleep or non-wear.

Forty-two metrics are retained. Interdaily stability, intradaily variability, nvRD, the four darkest-10-hour outcomes, the three dark Barroso outcomes, circadian variation, and disparity index are excluded. frequency_crossing_250 is retained using a gap-aware implementation. Brightest-10-hour and bright Barroso outcomes are interpreted conditionally on available valid waking-wear observations, not as complete 24-hour light schedules.

Calculate metrics

Clock-time outputs are converted to seconds since midnight. Missing observations remain on the regular time grid.

Metric helper functions
#| label: metric-helpers
#| filename: Metric helper functions
datetime_2_numeric <- function(x) {
  x |>
    mutate(
      across(
        where(is.POSIXct),
        \(value) value |> hms::as_hms() |> as.numeric()
      )
    )
}

frequency_crossing_gap_aware <- function(light, time, threshold) {
  stopifnot(
    is.numeric(light),
    inherits(time, "POSIXct"),
    length(light) == length(time),
    length(threshold) == 1L,
    is.numeric(threshold)
  )

  if (length(light) < 2L) {
    return(0L)
  }

  expected_epoch <-
    count_difftime(tibble(Datetime = time)) |>
    slice(1) |>
    pull(difftime) |>
    as.numeric(units = "secs")
  adjacent_in_time <- as.numeric(diff(time), units = "secs") == expected_epoch
  valid_pair <-
    !is.na(light[-length(light)]) &
    !is.na(light[-1L]) &
    adjacent_in_time
  threshold_state <- light >= threshold
  transitions <- abs(diff(as.integer(threshold_state)))

  as.integer(sum(transitions[valid_pair]))
}

The custom crossing helper fills a limitation in frequency_crossing_threshold(), which otherwise removes missing observations and can count a transition across a sleep or non-wear gap. It agrees with LightLogR for complete, regular data and does not count changes across missing intervals.
