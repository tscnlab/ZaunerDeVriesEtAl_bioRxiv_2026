Derive wake and sleep duration denominators

Timing differences are expressed relative to the behavioural interval in which the underlying metric is defined. The sleep interval follows the preparation workflow and extends from diary-recorded sleepprep (when the devices were positioned for the night) to wake. Diary intervals are restricted to participant-dates retained in the prepared metrics, with each interval assigned to its wake date. Mean sleep duration is the grand mean across all retained diary intervals, so each retained night receives equal weight. Mean wake duration is the complement of mean sleep duration to 24 hours. The three darkest-10-hour timing outcomes are classified as darkness-based; all other timing outcomes are classified as brightness-based.

Prepare modelling

The primary hypothesis (H1) is that wearing position affects a metric, potentially differently across measurement sites (i.e., a site × position interaction). The right-hand side of the formula is assembled here by appending the pre-specified random-effects structure (stored in the random column of metric_info) to the fixed-effects template ~ site*position. A helper then collects all formula column names (H0 and H1 variants) for programmatic iteration.

The table below summarises the modelling specification for every metric: the response variable, any pre-transformation applied, the modelling engine, the distributional family, and the full H1 formula. Confirmatory analyses deliberately omit p-value correction, because a non-significant position effect is the more scientifically desirable outcome.

Fit models

Models are fitted for each metric using the engine and family specified in the metadata. The fit_model() helper wraps lm, lmer, glmer, and glmmTMB and applies a three-step fallback strategy if a model fails to converge or is singular: first the Date random effect is dropped, then the random slope for position is simplified to a random intercept, and finally the interaction term is removed. This ensures a valid model is returned for every metric while preserving as much complexity as the data will support.

In addition to the main H1 model, several reduced models are fitted for each metric to support partial \[R^2\] decomposition later: models without the Date random effect, without the random slope for position, and without the position fixed effect altogether.

Helper functions
#| label: fit-model-helpers
#| filename: Helper functions
main_formula <- value ~ site*position + site + position + (position|Id) + (1|Date) 
red_formula <- value ~ site*position + site + position + (position|Id)
red_formula2 <- value ~ site*position + site + position + (1|Id)

rhs_same <- function(f1, f2) {
  identical(
    attr(terms(formula(f1, rhs = 1)), "term.labels"),
    attr(terms(formula(f2, rhs = 1)), "term.labels")
  )
}

fit_model <- function(data, formula, engine, family) {
  if(is.null(formula)) return()
  model <- 
  switch(engine,
         "lm" = lm(formula, data = data, contrasts = list(site = "contr.sum")),
         "glm" = glm(formula, data = data, family = family, contrasts = list(site = "contr.sum")),
         "lmer" = lmer(formula, data = data, contrasts = list(site = "contr.sum")),
         "glmer" = glmer(formula, data = data, family = family, contrasts = list(site = "contr.sum")),
         "glmmTMB" = glmmTMB(formula, data = data, family = family, contrasts = list(site = "contr.sum"))
         )

did_converge <- 
  performance::check_convergence(model) & !check_singularity(model)
 
  if(!did_converge) {
    if(rhs_same(main_formula, formula)) {
      formula <- formula |> update(. ~ . - (1 | Date))
    } else if (rhs_same(red_formula, formula)) {
      formula <-  formula |> update(. ~ . - (position|Id) + (1|Id))
    } else if (rhs_same(red_formula2, formula)) {
      formula <-  formula |> update(. ~ . - site:position)
    } else return(model)
      
  model <- fit_model(data, formula, engine, family)
  }
  
  model

}

Extract model results

Several quantities are extracted from every fitted H1 model:

  • p-values via car::Anova() (Type II/III Wald tests) for the fixed effects position, site, and their interaction.
  • Model diagnostics via performance::check_model() for visual inspection.
  • Random-effect standard deviations to quantify between-participant and between-date variability.
  • Estimated marginal means for the glasses reference level and pairwise contrasts of chest/wrist versus glasses (the two comparisons of primary interest).
  • Site-level contrasts within each wearing position to flag sites that deviate systematically.
  • Partial \[R^2\] values (Nakagawa–Schielzeth method) decomposed into contributions from the position fixed effect, the site fixed effect, the random slope for position across participants, the random effect of date, the residual participant intercept, and unexplained residual variance.

Result table

The full result table is assembled in two stages. First, all relevant columns are collected and reshaped into a wide format suitable for display: p-values, position effect estimates, random-effect standard deviations, and partial \[R^2\] components. For non-timing metrics, placement effects and standard deviations are normalised by the absolute reference value (glasses mean) on the modelling scale. Clock time has an arbitrary zero point, so an intercept-relative percentage such as a percentage of 16:00 is not meaningful. Brightness-based timing metrics are therefore normalised by the grand mean diary-defined wake duration, whereas darkness-based timing metrics are normalised by the grand mean diary-defined sleep duration. This expresses timing differences relative to the behavioural interval represented by each metric.

The gt table is then formatted with colour-coded cell backgrounds (red for significant negative deviations, blue for significant positive deviations), bold text for significant p-values, colored SVG arrows summarising site-level effects, and column spanners that group related columns. The table is saved as a high-resolution PNG for use in the manuscript.
