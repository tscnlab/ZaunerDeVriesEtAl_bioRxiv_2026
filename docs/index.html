2 Methods

2.1 Dataset

  • MeLiDos project: overview, collected modalities, size of data collection, times, brief summary of the protocol

Wearable light exposure data, diaries, logs, screening and discharge questionnaires, as well as ecological momentary assessments are used from the MeLiDos project. The MeLiDos project is a European project about Metrology for wearable light loggers and optical radiation dosimeters (Spitschan et al. 2024). In the second workpackage of the project, a field study was conducted in seven countries (Ghana, Costa Rica, Turkey, Spain, Germany, the Netherlands, and Sweden), using a harmonized protocol (Guidolin et al. 2024).

2.4.1 For measurement-based analysis

2.4.2 For metric-based analysis

  • table describing the metrics and parametrization, scaling, modelling family, engine
  • data were modelled with linear or generalized mixed-effect models.
  • generalized models used the tweedie, or poisson error distribution, all others a gaussian error distribution
  • models were constructed with the following formula in Wilkinson notation, based on theoretical considerations:

\[\text{metric} \sim \text{site} * \text{position} + (\text{position}|\text{participant}) + (1|\text{date}) \tag{1}\]

  • where metric is the outcome metric to be modelled. Fixed effects include the measurement site (e.g., Dortmund, Germany), in an interaction effect with the wearing position. The random effect structure consists of random slopes for wearing position per participant, as well as random intercepts per participant and random intercepts per calendar date (participant-day).
  • the glasses position is the reference level, with parameter estimates for differences due to the wrist or the chest.
  • site was sum-coded, meaning that the average across site is the reference.
  • If models failed to converge with the full model structure, they were refit in a stepwise procedure, where the model complexity was reduced. In the first instance, random intercepts per date were removed, followed by random slopes or position per participant. All models converged an were non-singular with that procedure.
  • Model diagnostics were created with the {performance} package and included plots for normality of residuals and random effects, homogeneity of variance, linearity, and collinearity.
  • Significance of effects were derived with the Anova function from the {car} package, using Wald chi-square tests, with a significance level of 0.05. Despite the large number of comparisons, no correction for multiple testing was applied. This is due to the fact that a null-result might tempt readers to assume equality between two positions, where the analysis tests for differences. Thus, each individual effect must be read with an type II error of 5%.
  • position and site effects and p-values were derived with the contrast function from the {emmeans} package, using the trt.vs.ctrl method for position and the eff.emmc method for site.
  • Marginal and conditional \(R^2\) values were calculated based on Nakagawa et al. (2017). Unique contributions of fixed effects to \(R^2\) were calculated as differences from a model with and without the effect in question.
  • To derive relative differences (on the modelling scale), effects were transformed with Equation 2

\[\text{relative effect} = (\frac{\text{effect}} {|\text{Intercept}|} -1) * 100\% \tag{2}\]

  • where the Intercept is the average effect for the glasses position and the average site.
  • to give contextual information when in the time of day wear position matters, a hierarchical generalized additive model accordiing to formula Equation 3

\[log_{10}(\text{melanopic EDI}) \sim s(\text{time}) + s(\text{time, position}) + s(\text{time, site}) + s(\text{time, participant}) + s(\text{participant-day}) \tag{3}\]

  • where the pattern of 30-minute aggregated and logarithmically scaled values of melanopic EDI are decomposed into a smooth (nonlinear effect) of time, deviation-smooths of wearing position over time, deviation-smooths of site over time, deviation-smooths of participants over time, and random intercepts of participant-days.
  • The effect of position is tested against a reduced model without the effect. Differences in AIC values larger than 2 are considered significant support for a more complex model with lower AIC.

4.3 Limitations

  • interindividual variance is high - results from individuals will vary strongly and it is unknown, whether and how different populations (here: adult, health, working indoors) differ in their bias
  • glasses-mount is near-eye level but not corneal and certainly not retinal
  • non-wear was removed, but was self-reported (will only cover part)
  • fixed sample size, reduced for UCR and TUM

4.4 Recommendations

  • remain with glasses-position (considered gold-standard), if (- momentary measurement values are the main outcome)?
    • protocol covers a short amount of time
    • occlusion is a likely issue
    • individuals or only a small sample are collected
    • temporal dynamic metrics are the main outcome
